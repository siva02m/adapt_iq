## Pending Action Items: Learner Progression & Adaptive Workflow

### Phase 1: Advanced Player Navigation & Locking
- [x] **Navigation Settings:** Course setting for Navigation Mode (Free Open vs. Progressive Unlock).
- [x] **Bottom Control Bar:** A sticky bottom bar in the `CoursePlayer` with "Previous" and "Next" buttons.
- [x] **Content Completion Tracking:** The "Next" button remains disabled until the learner has scrolled to the bottom of the content and all locked media (videos) have finished playing.

### Phase 2: The Adaptive Engine Lifecycle
- [ ] **1. Introduction Phase:** Learner navigates through all `IntroPages`.
- [ ] **2. Pre-Assessment Phase:** Left-nav unlocks the "Pre-Assessment". Learner takes the diagnostic test.
  - [x] **Interactive Assessment UI:** Renders confidence-based learning inputs (Sure, Not Sure, Don't Know).
  - [x] **Backend Integration:** Saves attempt logs to `attempts_ledger` via `/api/rounds/evaluate`.
  - [x] **Immediate Question-by-Question Feedback:** Pauses on response to display large colored banners, exact 4-box matrix states (MASTERED, MISINFORMED, etc.), and the custom feedback text.
  - [x] **Instant Diagnostics Summary:** Grouped scores, objective tags, mastery progress bars, and a historical breakdown of attempt selections and confidence profiles.
  - [x] **State Persistence:** Preserves diagnostic score sheets when learners navigate back and forth.
- [ ] **3. The Adaptive Split:** Backend calculates scores per Learning Objective (LO). The system automatically hides/skips Learning Modules for LOs the learner already mastered, and only unlocks the modules for LOs they failed.
- [ ] **4. Remediation Phase:** Learner goes through their customized path of unlocked `LearningModules`.
- [ ] **5. Final Assessment (FA) Phase:** Learner takes the final exam.
- [ ] **6. Results & Certification:** A final results page showing scores, completion status, and feedback.
